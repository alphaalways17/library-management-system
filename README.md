# Library Management System (Python + SQLAlchemy + SQLite)
This project is a fully functional Library Management System developed in **Google Colab** using Python, SQLAlchemy ORM, and SQLite database. It supports managing books, members, and book loans with an interactive text-based menu.
## Features
- Add books (title, author, ISBN, copies)
- Add members (name, email, phone)
- Issue books to members
- Return issued books
- Track active loans
- Search & list books
- Auto-update available copies
- Persistent database using Google Drive
## Technologies Used
- Python
- SQLAlchemy ORM
- SQLite Database
- Google Colab
- Drive-mounted persistence
